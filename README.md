# Rubika-Agent — Cloud + Python Brain

هدف این مخزن ساخت دستیار ماژولار برای کانال @poppy_play_time_HV است. پروژه باید تا حد ممکن رایگان بماند، اما هیچ سرویس یا سهمیه‌ای را نامحدود فرض نمی‌کنیم.

## جمع‌آوری خودکار ابری

- زمان‌بندی در GitHub Actions تعریف شده است: هر ۳۰ دقیقه فقط موعد را بررسی می‌کند و چرخهٔ جمع‌آوری پس از رسیدن فاصلهٔ پنج‌ساعته اجرا می‌شود.
- محیط Termux داخل Docker روی runner ابری GitHub اجرا می‌شود؛ اجرای دستور روزانه روی گوشی لازم نیست.
- این گردش‌کار کد جمع‌آوری داخل `termux/daily_discovery.py` را اجرا می‌کند و فقط فرادادهٔ عمومی را جمع‌آوری می‌کند؛ در این مرحله ویدئو دانلود یا در روبیکا منتشر نمی‌شود.
- گزارش معتبر به شاخهٔ `agent-brain-mega-v1` فرستاده می‌شود و نامزدهای TikTok پس از اعتبارسنجی به صف پایدار D1 می‌روند. خبرهای رسمی Mob مسیر جداگانه‌ای دارند.
- فایل‌های جمع‌آوری Termux داخل مخزن بخشی از محیط ابری هستند؛ اسکریپت‌های نصب و اجرای روزانه روی گوشی دیگر جزو مسیر ضروری پروژه نیستند.

راهنمای جزئیات: [docs/CLOUD_DISCOVERY.md](docs/CLOUD_DISCOVERY.md).

## وظایف اصلی
- Python: تصمیم‌گیری، بررسی فایل، تشخیص تکراری‌ها، سیاست محتوا، آماده‌سازی دسته و مدیریت تلاش‌های ارسال.
- Cloudflare Worker + D1: API کنترل و حافظهٔ فراداده‌ها/تاریخچه.
- Workers AI فقط برای تشخیص وجود موسیقی در صدای ویدئو و ترجمهٔ فارسی خبرهای رسمی استفاده می‌شود؛ راهنمای خطا با قواعد محلی Python کار می‌کند و هیچ درخواست AI نمی‌فرستد. تشخیص نام آهنگ و تحلیل تصویری ادیت در حال حاضر فعال نیست.
- MEGAcmd: آپلود، دانلود و حذف امن فایل‌های مرحلهٔ آماده‌سازی.
- GitHub Actions: تست خودکار و اجرای کارهای موقت؛ runner دائمی نیست.
- Cobalt: دریافت رسانه از لینک‌های عمومی پشتیبانی‌شده؛ در آزمایش قبلی دریافت TikTok و Instagram از GitHub runner موفق بود.
- Relay اختیاری Render: برای ویدئوی عمومی YouTube که صاحب پروژه اجازهٔ دانلود و بازنشر آن را دارد؛ با توکن، بررسی فایل و محدودیت حجم/مدت. این سرویس هنوز Deploy نشده؛ جزئیات در docs/AUTHORIZED_RELAY.md.
- Rubka 8.1.7: ارتباط با روبیکا؛ روش‌های تأییدشده در محیط قبلی sync بوده‌اند و پاسخ‌های JSON باید بررسی شوند.

## مغز Python
مشخصات ماژول‌ها در docs/AGENT_BRAIN_V1.md آمده است. دو مسیر محتوا از هم جدا هستند:
1. ادیت‌های Poppy Playtime از TikTok، YouTube و Instagram، با بررسی تکراری‌بودن، خروجی عمودی 1080×1920، آهنگ و تصمیم‌های محتوایی.
2. رسانه‌های رسمی Mob Entertainment شامل ویدیو، عکس و صدا؛ کپشن اصلی و ترجمه فقط وقتی در دسترس باشند قالب‌بندی می‌شوند.

فهرست منابع قابل‌اعتماد در config/trusted_sources.json عمداً خالی است تا صاحب پروژه منابعش را انتخاب کند.

## محدودیت‌های مهم
- کشف زندهٔ TikTok باید از لاگ گردش‌کار ابری بررسی شود؛ تست parser به‌تنهایی موفقیت منبع زنده را ثابت نمی‌کند.
- کشف Instagram از ایندکس‌های عمومی Bing/DuckDuckGo انجام می‌شود و برای جلوگیری از نامزدهای کهنه، لینک‌های فاقد تاریخ یا قدیمی‌تر از ۹۰ روز پذیرفته نمی‌شوند. این روش تضمین پنج نتیجه در هر اجرا نمی‌دهد.
- جست‌وجوی YouTube با yt-dlp در حالت flat لینک‌ها را بدون دانلود در گزارش ثبت می‌کند. دریافت ویدئوی YouTube در runner ابری هنوز نیازمند آزمایش زنده است و Relay اختیاری آن Deploy نشده است.
- ارزیابی تصویری/شنیداری واقعی برای تشخیص ادیت سطح بالا، توهین‌ها و وجود موسیقی به یک طبقه‌بند واقعی نیاز دارد. تا پیش از اتصال و آزمون آن، مغز نباید نامطمئن‌ها را خودکار تأیید کند.
- رسانهٔ دریافت‌شده هنوز در چرخهٔ یکپارچهٔ دانلود → اعتبارسنجی → MEGA → D1 وصل نشده؛ اجزای جداگانه و تست‌هایشان وجود دارند، اما اجرای سرتاسری واقعی باید ثابت شود.
- Migrationهای جدید D1 باید جداگانه و آگاهانه روی دیتابیس remote اعمال شوند؛ deploy معمولی Worker لزوماً migration را اجرا نمی‌کند.
- انتشار تولیدی تا زمان تکمیل آزمایش‌های سرتاسری، مجوز منبع، moderation واقعی و test-channel validation خاموش می‌ماند.
- Secretها هیچ‌وقت داخل کد، README، report یا لاگ قرار نمی‌گیرند. حساب رایگان MEGA محدودیت فضا و انتقال داده دارد.

## اجرای آزمایش یک‌ویدئویی سرتاسری
راهنمای ساخت secret مشترک و اجرای دستی مسیر گزارش گوشی → مغز AI → MEGA/D1 → روبیکا در [docs/END_TO_END_SMOKE.md](docs/END_TO_END_SMOKE.md) است. این workflow فقط با اجرای دستی فعال می‌شود و در هر اجرا حداکثر یک ویدئو می‌فرستد.
