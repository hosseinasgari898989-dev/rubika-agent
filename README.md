# Rubika-Agent — Cloud + Python Brain

هدف این مخزن ساخت دستیار ماژولار برای کانال @poppy_play_time_HV است. پروژه باید تا حد ممکن رایگان بماند، اما هیچ سرویس یا سهمیه‌ای را نامحدود فرض نمی‌کنیم.

## اجرای جمع‌آوری اطلاعات از Termux
اگر مخزن را از قبل داری، اول وارد ریشهٔ آن شو و شاخهٔ آزمایشی را بگیر. اگر هنوز نداری، دستورهای راهنمای Termux در `docs/TERMUX_DAILY_DISCOVERY.md` را اجرا کن.

**راه‌اندازی یک‌باره:**
    bash termux/bootstrap.sh

بعد از ورود یک‌باره به GitHub با `gh auth login` و اجرای `gh auth setup-git`، دستور روزانه فقط این است:
    bash termux/daily.sh

این دستور اول شاخهٔ آزمایشی را به‌صورت امن به‌روز می‌کند، سپس فقط اطلاعات عمومی و URL ویدیوها را جمع می‌کند؛ هیچ رسانه‌ای دانلود نمی‌شود و چیزی در روبیکا منتشر نمی‌کند. گزارش در `artifacts/termux_discovery.json` ذخیره و فقط به شاخهٔ آزمایشی `agent-brain-mega-v1` فرستاده می‌شود. برنامه در شاخه یا مخزن دیگری push نمی‌کند.

TikTok و YouTube در مرحلهٔ کشف فقط metadata می‌فرستند؛ تاریخ انتشار در گزارش اطلاعات تکمیلی است و برای اجرای تست سرتاسری شرط نیست. مسیر Instagram ممکن است صفر نتیجه بدهد یا metadata ناقص پیدا کند. گزارش گوشی به‌تنهایی رسانه دانلود/منتشر نمی‌کند؛ workflow دستی مستقل، فایل را دانلود و اعتبارسنجی می‌کند و فقط پس از عبور از بررسی‌های مغز آن را می‌فرستد.

## کشف ابری و صف‌بندی
- مسیر فعال در main فایل `.github/workflows/termux-docker-discovery.yml` است: GitHub Actions هر ۳۰ دقیقه وضعیت زمان‌بندی را بررسی می‌کند و فقط وقتی ۵ ساعت از آخرین دریافت موفق صف گذشته باشد، جمع‌آوری metadata را در Termux Docker اجرا می‌کند. گزارش JSON سپس اعتبارسنجی و به صف D1 فرستاده می‌شود.
- این مسیر فرمان روزانه روی گوشی نمی‌خواهد، ویدیو دانلود نمی‌کند و چیزی در Rubika منتشر نمی‌کند. فایل `docs/TERMUX_DAILY_DISCOVERY.md` توضیح مسیر قدیمی/آزمایشی گوشی است، نه زمان‌بند فعال ابری.

## وظایف اصلی
- Python: تصمیم‌گیری، بررسی فایل، تشخیص تکراری‌ها، سیاست محتوا، آماده‌سازی دسته و مدیریت تلاش‌های ارسال.
- Cloudflare Worker + D1: API کنترل و حافظهٔ فراداده‌ها/تاریخچه.
- Workers AI فقط برای تشخیص موسیقی از صدای ویدیو با Clef Omni استفاده می‌شود؛ تصمیم نامطمئن نیازمند بازبینی انسانی است. ترجمهٔ خبرهای رسمی از Groq و در صورت نیاز OpenRouter استفاده می‌کند و هر درخواست در D1 ثبت می‌شود. موتور تعمیر کد با Groq/OpenRouter تشخیص و بازبینی مستقل انجام می‌دهد، اما فقط پس از تست‌های قطعی PR می‌سازد و خودکار merge نمی‌کند. تشخیص نام آهنگ و تحلیل تصویری ادیت هنوز فعال نیست.
- MEGAcmd: آپلود، دانلود و حذف امن فایل‌های مرحلهٔ آماده‌سازی.
- GitHub Actions: تست خودکار و اجرای کارهای موقت؛ runner دائمی نیست.
- Cobalt: دریافت رسانه از لینک‌های عمومی پشتیبانی‌شده؛ دریافت واقعی رسانه باید برای هر منبع در CI و پیش از انتشار نهایی اعتبارسنجی شود.
- Relay اختیاری Render: برای ویدئوی عمومی YouTube که صاحب پروژه اجازهٔ دانلود و بازنشر آن را دارد؛ با توکن، بررسی فایل و محدودیت حجم/مدت. این سرویس هنوز Deploy نشده؛ جزئیات در docs/AUTHORIZED_RELAY.md.
- Rubka 8.1.7: ارتباط با روبیکا؛ روش‌های تأییدشده در محیط قبلی sync بوده‌اند و پاسخ‌های JSON باید بررسی شوند.

## مغز Python
مشخصات ماژول‌ها در docs/AGENT_BRAIN_V1.md آمده است. دو مسیر محتوا از هم جدا هستند:
1. ادیت‌های Poppy Playtime از TikTok و YouTube Shorts، با بررسی تکراری‌بودن، اعتبار رسانه و تصمیم‌های محتوایی.
2. رسانه‌های رسمی Mob Entertainment شامل ویدیو، عکس و صدا؛ کپشن اصلی و ترجمه فقط وقتی در دسترس باشند قالب‌بندی می‌شوند.

مجوزهای منبع در config/trusted_sources.json ثبت شده‌اند و قوانین جداگانهٔ شش سازندهٔ TikTok در config/tiktok_source_policy.json هستند. مجوز منبع، مرتبط‌بودن تک‌تک پست‌ها یا اعتبار مدیا را تضمین نمی‌کند؛ همهٔ بررسی‌ها همچنان لازم‌اند.

## محدودیت‌های مهم
- جمع‌آوری فعال از مسیر زمان‌بندی‌شدهٔ cloud + Termux Docker در GitHub Actions است؛ اجرای قدیمی روی گوشی مسیر ضروری روزانه نیست.
- Instagram از مسیر فعال ادیت کنار گذاشته شده است؛ مستندات/کد تاریخی آن به‌معنی فعال‌بودن این منبع در صف جاری نیست.
- جست‌وجوی YouTube با yt-dlp در حالت flat اجرا می‌شود و لینک‌ها را بدون دانلود در گزارش ثبت می‌کند. تاریخ نامشخص مانع تست سرتاسری نیست؛ گلوگاه واقعی دانلود YouTube دسترسی Runner است و برای آن هنوز Relay جداگانه Deploy نشده است.
- ارزیابی تصویری/شنیداری واقعی برای تشخیص ادیت سطح بالا، توهین‌ها و وجود موسیقی به یک طبقه‌بند واقعی نیاز دارد. تا پیش از اتصال و آزمون آن، مغز نباید نامطمئن‌ها را خودکار تأیید کند.
- مسیر ادیت تا کانال تست قبلاً ارسال‌های واقعی موفق داشته است، اما مقصد اصلی فعلی عمداً مسدود است: preflight احراز هویت Bot را قبول کرد و به‌دلیل اینکه secret RUBIKA_CHANNEL_GUID هنوز شناسهٔ کانال تست است، اجازهٔ ادامه نداد. بنابراین اجرای سرتاسری برای کانال اصلی هنوز ثابت نشده است.
- Migrationهای جدید D1 باید جداگانه و آگاهانه روی دیتابیس remote اعمال شوند؛ deploy معمولی Worker لزوماً migration را اجرا نمی‌کند.
- انتشار کانال اصلی تا تعیین GUID اصلی در secret RUBIKA_CHANNEL_GUID و عبور از preflight read-only خاموش می‌ماند. خبر Mob علاوه بر این به gate مستقل خودش، lifecycle production و تنظیمات production نیاز دارد.
- Secretها هیچ‌وقت داخل کد، README، report یا لاگ قرار نمی‌گیرند. حساب رایگان MEGA محدودیت فضا و انتقال داده دارد.

## اجرای آزمایش یک‌ویدئویی سرتاسری
راهنمای ساخت secret مشترک و اجرای دستی مسیر گزارش گوشی → مغز AI → MEGA/D1 → روبیکا در [docs/END_TO_END_SMOKE.md](docs/END_TO_END_SMOKE.md) است. این workflow فقط با اجرای دستی فعال می‌شود و در هر اجرا حداکثر یک ویدئو می‌فرستد.
