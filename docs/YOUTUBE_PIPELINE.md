# مسیر پردازش یوتیوب

این فاز جدا از صف انتشار فعلی ساخته می‌شود. در مرحلهٔ فعلی هیچ ویدیویی دانلود، ترجمه یا در روبیکا منتشر نمی‌شود؛ ماژول فقط سیاست کانال و برنامهٔ پردازش را می‌سازد و فرمان yt-dlp را بدون اجرا برمی‌گرداند.

## انتخاب کانال‌ها

- انتخاب اصلی از رکوردهای sources با platform برابر youtube و enabled برابر 1 می‌آید؛ مالک می‌تواند کانال را در کنسول موجود فعال یا غیرفعال کند.
- فایل config/youtube_pipeline.json فهرست persian_subtitle_channels را نگه می‌دارد. فقط کانال‌هایی که کلیدشان دقیقاً به همان کلید نرمال‌شده برسد، نیازمند زیرنویس فارسی هستند.
- کلید کانال را می‌توان به شکل @handle، handle بدون @، شناسهٔ کانال UC... یا URL استاندارد کانال ثبت کرد.
- این فهرست اکنون خالی است تا هیچ کانالی بدون انتخاب مالک، ناخواسته مشمول پردازش زیرنویس نشود.

## سیاست رسانه

- آستانهٔ رسانهٔ بزرگ 700,000,000 بایت است. برای دانلودهای بزرگ، argv ساخته‌شده گزینهٔ HTTP chunk ده مگابایتی yt-dlp را فعال می‌کند. دانلودهای DASH/HLS از قطعه‌های fragment خودشان استفاده می‌کنند.
- دریافت ناقص قابل ادامه است و تعداد retry و fragmentهای هم‌زمان محدود است.
- اگر کانالی زیرنویس بخواهد، برنامهٔ رونویسی به قطعه‌های حداکثر 15 دقیقه‌ای تقسیم می‌شود؛ حد پیش‌فرض 96 قطعه است. این کار از فرستادن متن یک ویدیوی بلند در یک درخواست جلوگیری می‌کند.
- پیکربندی اولیهٔ Whisper روی مدل small و int8 CPU است تا مرحلهٔ اول روی runner رایگان CPU قابل بررسی باشد؛ زمان واقعی و کیفیت باید با یک اجرای آزمایشی بدون انتشار سنجیده شود.

## ترتیب ادامهٔ توسعه

1. این مرحله: سیاست کانال‌ها، اعتبارسنجی URL، ساخت argv امن و برنامهٔ تقسیم قطعه‌ها با تست‌های آفلاین.
2. مرحلهٔ بعد: downloader واقعی و جداسازی صدا با ffmpeg، با سقف حجم و زمان و امکان resume.
3. بعد: faster-whisper با dependency نسخه‌بندی‌شده و خروجی SRT زمان‌دار.
4. سپس: ترجمهٔ متن SRT از Groq با سهمیهٔ روزانهٔ جداگانهٔ YouTube، ثبت امن و fail-closed. سهمیهٔ رسمی Mob دست‌نخورده می‌ماند.
5. بعد از تست خروجی فارسی: ساخت SRT نهایی و حک زیرنویس با فونت Vazirmatn داخل ریپو.
6. ادغام با صف واقعی در PR مستقل؛ تا وقتی تست و تأییدهای لازم کامل نشده‌اند، هیچ workflow زمان‌بندی‌شده یا مسیر انتشار کانال اصلی فعال نمی‌شود.

این مرحله migration دیتابیس، Secret، Workflow انتشار، quiet_hours یا منطق کانال اصلی را تغییر نمی‌دهد.
